<h2><em>凌辉Bot是什么?</em></h2>
凌辉Bot是一个用于QQ群的机器人，同时是一个应该达到了平均水准的<em>FurBot</em>，可以为您提供一定的<em>
Furry服务</em>，它使用OneBot V11标准的NoneBot作为Robot后端、NapCat作为QQ协议端。使用了部分<em>
NoneBot商店插件</em>以改进凌辉Bot的部分功能。
